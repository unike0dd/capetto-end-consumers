# Cappeto End Consumers

Responsive consumer storefront for customers of small and medium restaurants, cafés, food stalls, home-based food businesses, and other independent sellers. It reads the public product catalog from the Cappeto owner site and displays available products, images, prices, categories, search, a bilingual interface, light and dark themes, and a local order bag.

The interface is designed for people using mobile, tablet, laptop, and desktop devices, including people who navigate with a keyboard, use a screen reader, enlarge browser content up to 250%, prefer reduced motion, or use high-contrast settings.

Live site: https://unike0dd.github.io/capetto-end-consumers/

Product source: https://unike0dd.github.io/cappeto/data/storefront.json


## Inclusive and adaptive interface

The shared `adaptive.css` and `adaptive.js` layer provides responsive reflow for mobile, tablet, laptop, desktop, orientation changes, browser visual viewports, and browser zoom through 250%. Semantic labels, keyboard-operable controls, visible focus, status announcements, reduced-motion support, and high-contrast adjustments help make the storefront available to people with disabilities. The shopping-bag drawer retains fixed actions while its item list scrolls independently on small screens.
