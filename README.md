# Cappeto End Consumers

Responsive consumer storefront for Cappeto. It reads the public product catalog from the Cappeto owner site and displays available products, images, prices, categories, search, bilingual UI, light/dark themes, and a local order bag.

The interface is designed for mobile, tablet, laptop, desktop, keyboard use, and browser zoom up to 250%.

Live site: https://unike0dd.github.io/capetto-end-consumers/

Product source: https://unike0dd.github.io/cappeto/data/products.json
