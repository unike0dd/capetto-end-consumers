# Access-Control Matrix

| Actor | Public catalog | Own records | Business records | Administration |
|---|---|---|---|---|
| Visitor | Read | None | None | None |
| Consumer | Read | Own only | None | None |
| Staff | Read | Assigned only | Explicit least privilege | None |
| Business owner | Read | Business scope | Business scope | No platform admin |
| Maintainer | No runtime privilege implied | None implied | None implied | Repository only |
| Security auditor | Evidence only | Approved evidence | Approved evidence | No mutation |

GitHub membership never grants customer-data access.
